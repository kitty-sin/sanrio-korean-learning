## 🔍 RDQ 盲點探索：8 大關鍵語法與功能檢核 (Forgotten Points)

### 1. 助詞自動掛載與代名詞變形 (Particle Engine)
- **主語**：
  - 第一人稱自稱 `나` (平語) ➔ `나는` / `내가`
  - 第一人稱謙稱 `저` (敬語) ➔ `저는` / `제가`
  - 第二人稱 `너` ➔ `너는` / `네가 (發音 니가)`
  - 一般名詞：末字有收音接 `은 / 이`，無收音接 `는 / 가`
- **受語**：
  - 末字有收音接 `을`（如 `밥` ➔ `밥을`）
  - 末字無收音接 `를`（如 `커피` ➔ `커피를`）

### 2. 現在式的雙軌呈現
- **一般現在式 (Present Simple)**：
  - 最高敬語：`저는 커피를 마십니다.`
  - 日常敬語：`저는 커피를 마셔요.`
  - 平語：`나는 커피를 마셔.`
- **現在進行式 (Present Continuous -고 있다)**：
  - 最高敬語：`저는 커피를 마시고 있습니다.`
  - 日常敬語：`저는 커피를 마시고 있어요.`
  - 平語：`나는 커피를 마시고 있어.`

### 3. 過去式變形 (-았/었/했-)
- 陽性母音 (`ㅏ, ㅗ`) ➔ `-았습니다 / -았어요 / -았어` (如 `보다` ➔ `봤어요`)
- 陰性母音 (其他母音) ➔ `-었습니다 / -었어요 / -었어` (如 `마시다` ➔ `마셨어요`, `먹다` ➔ `먹었어요`)
- `하다` 動詞 ➔ `-했습니다 / -했어요 / -했어` (如 `공부하다` ➔ `공부했어요`)

### 4. 未來式變形 (-(으)ㄹ 것이다 / -(으)ㄹ 거예요)
- 有收音 ➔ `-을 것입니다 / -을 거예요 / -을 거야` (如 `먹다` ➔ `먹을 거예요`)
- 無收音 / `ㄹ` 收音 ➔ `-ㄹ 것입니다 / -ㄹ 거예요 / -ㄹ 거야` (如 `마시다` ➔ `마실 거예요`)

### 5. 7 大不規則動詞容錯 (Irregulars Handling)
- 支援 `ㄷ` (듣다➔들어요), `ㅂ` (돕다➔도와요, 춥다➔추워요), `ㅅ` (짓다➔지어요), `ㅡ` 脫落 (쓰다➔써요), `르` (부르다➔불러요) 等常用動詞精準解析。

### 6. 自動詞與形容詞支援（受語留空或轉為地點）
- 若車卡2留空，自動組裝為不及物動詞句（如 `저는 자요` 我睡覺、`날씨가 좋아요` 天氣好）。

### 7. 雙向輸入支援（手動打字 ＋ 萌趣常用單字庫點選）
- 用戶可直接打中文（如「我」、「咖啡」、「喝」）或韓文（如 `나`, `커피`, `마시다`）。
- 同時提供「主語車廂選單」、「受語車廂選單」、「動詞車廂選單」一鍵點選。

### 8. 發音、羅馬拼音與音變讀音
- 每個時態敬語句型均自動生成標準羅馬拼音，並標記連音化/激音化/鼻音化後的實際讀音，支援 0.5x / 0.8x / 1.0x Web Speech 朗讀與一鍵複製。
